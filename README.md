# دفتري · Daftari

تطبيق أندرويد عربي لتسجيل الديون والإيجارات — لصاحب المحل/البقالة ولصاحب السوق/المؤجر. يشتغل بدون إنترنت (Room) ويزامن مع الخادم لما يتوفر.

- `android/` — Kotlin + Jetpack Compose، الحزمة `com.daftari.app`. الاسم يتغير من `core/AppInfo.kt` و`res/values/strings.xml`.
- `server/` — Node/TypeScript (Fastify + Postgres/Neon): رمز التحقق (WhatsApp Cloud / SMS)، Google، شات «مدين» (Groq ثم Gemini)، الرفع الذكي، النسخ الاحتياطي، أكواد برو.
- خطوات التشغيل: `server/DEPLOY_AR.md`.

## Build
```
cd android
DF_STORE_FILE=... DF_STORE_PASSWORD=... DF_KEY_ALIAS=... DF_KEY_PASSWORD=... ./gradlew testDebugUnitTest assembleRelease
cd ../server && npm install && npm test
```

Google sign-in / Drive: put `DF_GOOGLE_WEB_CLIENT_ID=…apps.googleusercontent.com` (the **Web** OAuth client of the Cloud project)
in `android/local.properties` (never committed), or pass `-PDF_GOOGLE_WEB_CLIENT_ID=…` / the env var of the same name, then rebuild —
no code change. Sign-in is Credential Manager (`GetGoogleIdOption` authorized accounts → all accounts → `GetSignInWithGoogleOption`,
serverClientId = the Web client); Drive is `AuthorizationClient` with `drive.appdata` on the same account. Both also need the
**Android** OAuth client (package `com.daftari.app` + the signing SHA-1) in the same project and the Google Drive API enabled.

## 1.1.0
- Google Drive: نسخ احتياطي الآن، نسخ يومي تلقائي لما يتوفر نت، «استرجاع» بقائمة النسخ بالتاريخ (مجلد مخفي appDataFolder). وبدون أي إعداد: «حفظ نسخة في Drive» و«استيراد نسخة» عبر قائمة الجوال.
- صيغة نسخة واحدة `.daftari` (ZIP: manifest.json + data.json، تشفير اختياري AES-256-GCM) — راجع `docs/backup-format.md`. الاسترجاع يدمج بدون تكرار، ومتاح من أول تشغيل.
- «مدين» يشتغل بدون نت: فهم عربي (لهجة يمنية/خليجية) لإضافة دين/سداد، الرصيد، كشف الحساب، الأكثر عليهم، ملخص اليوم، زبون جديد، تذكير، تراجع — بطاقة تأكيد قبل أي حفظ. يفتح ملف `.daftari` ويجاوب عنه.
- «انتقل من تطبيق آخر»: CSV / Excel (.xlsx و .xls القديم) / JSON / SQLite، أي شكل (عملية بكل سطر، رصيد لكل زبون، تفصيل شهري)، تعديل ربط الأعمدة ويتذكره، تخطي المكرر، ومطابقة الإجمالي.
- «السجل»: دائم ومختوم SHA-256 بسلسلة، لقطات قبل/بعد، ما ينحذف حتى مع مسح البيانات، داخل النسخ، استرجاع أي محذوف أو معدّل. يفتح بالبصمة + الرمز معاً. «كشف السجل» PDF/Excel بفلاتر.
- عملات لكل عملية (ريال يمني / سعودي / دولار) بسعر صنعاء أو عدن المحفوظ مع العملية، وطريقة الدفع (نقداً / حوالة برقمها وشركتها وصورة الإيصال) مع تنبيه رقم الحوالة المكرر.

## 1.1.1
- طريقة دفع جديدة «محفظة»: ون كاش، جيب، جوالي، فلوسك، حاسب (كل واحدة بأيقونتها) أو «أخرى» باسم مكتوب، ورقم العملية وجوال المرسل (اختياريان) وصورة الإيصال.
- الحوالة: الكريمي / النجم / الحزمي فقط، أو «أخرى» باسم مكتوب. رقم الحوالة/العملية اختياري، وتنبيه الرقم المكرر يظهر عند كتابته.
- الطريقة والشركة/المحفظة والرقم تظهر في الكشف وPDF وExcel و«السجل» والنسخ `.daftari` (المخطط 2.1، مع ترحيل نسخ 2.0) واستيراد ملفات التطبيقات الأخرى، و«مدين» يفهم «محمد سدد 5000 جوالي رقم 778899».
- صورة الإيصال تُربط بالدفعة نفسها (وتظهر تحتها في الحركات)، وقفل الرمز بعد 5 محاولات خاطئة لمدة 5 دقائق محفوظ ولا يُلغى بإغلاق الشاشة، وإصلاح أقواس «(.daftari)».
- كل نصوص التطبيق بالعربية الفصحى، و«مدين» يفهم اللهجة ويرد بالفصحى (اختبار يمنع عودة اللهجة).
- أيقونات المحافظ من صفحات Google Play: ONE Cash (`com.one.onecustomer`)، Jaib (`com.ahd.jaib`)، Jawali (`com.ama.wecashmobileapp`)، Floosak (`co.ysys.floosak`). «حاسب» خدمة من بنك الكريمي بلا تطبيق مستقل، فلها شارة بحرف «ح».

## 1.1.2
- شعارات شركات الحوالات على أزرارها وفي الحركات وبطاقة تأكيد «مدين»: الكريمي (أيقونة تطبيق «الكريمي جوال» `com.KuraimiBank` من Google Play)، النجم (شعار شبكة النجم للحوالات المالية من حسابها الرسمي @annajmplus / annajmplus.com)، الحزمي (شعار شركة الحزمي للصرافة من موقعها الرسمي alhazmiex.com). «أخرى» كما هي.
- شعار «حاسب» (الشعار الذي أرسله صاحب التطبيق) بدل شارة «ح».
- أسعار الصرف: جدول «شراء | بيع» لكل عملة في صنعاء وعدن، الاثنان قابلان للتعديل و«تحديث من الإنترنت» يملأهما. كل العمليات تُحسب بسعر الشراء فقط، وسعر البيع للعلم. الجدول يُحفظ داخل نسخة `.daftari` (المخطط 2.2).

## 1.1.3
- صورة الإيصال الاختيارية (حوالة / محفظة): زرّان متجاوران «التقاط صورة» (الكاميرا مباشرة) و«اختيار من المعرض». الكاميرا تحفظ في مجلد خاص بالتطبيق عبر FileProvider دون أي صلاحية تخزين أو كاميرا؛ الإلغاء لا يترك ملفاً، وإن لم يوجد تطبيق كاميرا تظهر رسالة ويُفتح المعرض.
- الصورة (من الكاميرا أو المعرض) تُصغَّر إلى 1600 بكسل JPEG بجودة 80 وتُعدَّل حسب اتجاه التصوير، وتظهر مصغّرتها في نافذة الدفعة مع «إزالة»، وتُربط بالدفعة نفسها عند الحفظ.
- نافذة الدفعة تحتفظ بالمبلغ والحقول والصورة عند تدوير الشاشة أو إذا أغلق النظام التطبيق أثناء التصوير.

## 1.1.4
- الدخول بحساب Google فقط (حُذف التحقق برقم الجوال وواتساب وSMS). أول تشغيل: الشاشة نفسها بالشعار وبطاقتَي «صاحب محل / صاحب سوق» وزر «المتابعة باستخدام Google» فقط. بعد الدخول: كلمة سر للتطبيق (PBKDF2 مملّح) + تفعيل البصمة.
- كل تشغيل بعد ذلك: الشاشة نفسها، وبدل Google: كلمة السر + «فتح» + «البصمة» (تُعرض تلقائياً إن فُعّلت) و«نسيت كلمة المرور؟» (تحقق بحساب Google نفسه ثم كلمة سر جديدة).
- دفتران بحساب Google واحد: «صاحب محل» و«صاحب سوق»، لكل منهما قاعدة بيانات و«سجل» وتذكيرات وملف تعريف منفصل. الدفتر الموجود قبل 1.1.4 يبقى بأسماء ملفاته الأصلية (لا نقل ولا فقدان)، والدور الآخر بملفات `daftari_<role>.db`. التبديل من بطاقات شاشة الدخول أو الإعدادات ← «الدفاتر»، دون تسجيل دخول جديد (يعيد تشغيل التطبيق).
- نسخ Drive منفصلة لكل دفتر (`Daftari-shop-…` / `Daftari-market-…`، والنسخ القديمة بلا وسم تتبع الدفتر الأصلي)، والإبقاء على آخر 30 لكل دفتر. النسخ التلقائي إجباري يومياً الساعة 2:00 صباحاً (يمكن تغيير الوقت فقط)، عبر WorkManager يعيد جدولة نفسه لموعد اليوم التالي، ويعيد المحاذاة عند تغيير المنطقة الزمنية/الساعة أو إعادة التشغيل. يغطي الدفتر المفتوح، ويُرفع الدفتر الذي تغادره قبل التبديل.
- أسباب فشل الدخول بالفصحى (خطأ 10 = عدم تطابق SHA-1/الحزمة، لا يوجد حساب، خدمات Google Play، الإنترنت، الإلغاء)، وبعد فشل Google يظهر خيار مؤقت «تابِع بكلمة سر فقط» حتى لا يُحرم من بياناته.
